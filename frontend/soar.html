Conectar Router de Red Empresarial (EDL MikroTik / pfSense / FortiGate)

Además de proteger este servidor localmente mediante netsh advfirewall, CyberShield publica en tiempo real un Feed Dinámico de Lista Negra Perimetral (EDL) en texto plano (una IP por línea) para que el Router o Firewall principal corte el tráfico del atacante en toda la red de la empresa (Switches, VLANs y otros servidores).

Abrir Feed
1. Comando listo para Router MikroTik (RouterOS v6 / v7): 
/ip firewall filter add chain=forward src-address-list=CyberShield_Block action=drop comment="CyberShield SOAR IPS Perimetral" place-before=0
/system scheduler add name="Sync_CyberShield_SOAR" interval=30s on-event="/tool fetch url=\"http://192.168.18.10:8000/api/soar/blocklist.txt\" dst-path=cybershield.txt; :foreach ip in=[:toarray [/file get cybershield.txt contents]] do={ /ip firewall address-list add list=CyberShield_Block address=\$ip timeout=15m }"
2. pfSense / OPNsense (URL Table Alias):
Ir a Firewall → Aliases → URLs, elegir tipo URL Table (IPs), pegar la URL del Feed con refresco cada 1 min y asociar el Alias a una regla Block en la interfaz WAN/LAN.
3. Fortinet FortiGate (External Threat Feed):
Ir a Security Fabric → External Connectors → Create New → IP Address Threat Feed, ingresar la URL en vivo y usarla como origen Deny en Firewall Policy.
